# Математика: тренажер для молодшої школи

Вебзастосунок для розв'язування математичних прикладів. Завдання згруповані за класами, розділами й рівнями складності. Мета — швидко потренуватися без підручника й зошита: обрав клас і тему, і застосунок видає набір випадкових прикладів. Зараз є 2 і 5 класи (по 9 розділів), далі весь курс НУШ. Застосунок адаптований для телефонів і планшетів (насамперед Android) і встановлюється на головний екран як PWA.

## Як влаштовано

```
index.html, css/            інтерфейс
js/core/                    чиста логіка: без DOM, мережі та сховища
  rng.js                    детермінований генератор випадкових чисел
  expr.js                   парсер і обчислення виразів
  generators.js             генератори прикладів (arithmetic, expression, compare, template, decimal, fraction)
  numbers.js                точна арифметика десяткових і звичайних дробів
  session.js                тренувальна сесія, перевірка відповіді, зірки
  progress.js               прогрес із журналу сесій
  validate.js               перевірка контенту
js/app/                     платформна частина
  main.js                   екрани й навігація (адреси #/grade/g2, #/topic/g2-mul…)
  answer-input.js           поле відповіді й клавіатура під тип відповіді
  content.js                завантаження data/ (без кешу, при кожному запуску)
  storage.js                localStorage і сховище прогресу
js/config.js                налаштування
data/                       контент (JSON), формат описано в docs/CONTENT.md
tests/                      тести core-логіки й контенту (tests/index.html)
```

Збірки немає: це звичайні ES-модулі, тож репозиторій публікується на GitHub Pages як є.

### Задел під мобільний застосунок

- **Контент не залежить від платформи.** Нативний застосунок читатиме ті самі JSON (з GitHub Pages або вбудовані в застосунок).
- **Правила описані даними, а не кодом.** Завдання задаються декларативно (генератор + параметри), тож у новій мові треба реалізувати лише 6 невеликих генераторів, парсер виразів і точну арифметику дробів з `js/core/`. Їхня поведінка зафіксована в `docs/CONTENT.md` і `tests/core.test.js`, і ці тести можна перенести як специфікацію.
- **Логіка відокремлена від інтерфейсу.** `js/core/` не торкається DOM і сховища. Якщо мобільний застосунок робитимуть на React Native або Capacitor, ці модулі можна взяти без змін.
- **Прогрес зберігається як журнал завершених сесій**, а не як готові лічильники. Такий журнал легко синхронізувати з сервером, коли з'являться акаунти.
- **Сховище прогресу сховане за інтерфейсом** (`storage.js`: `progressStore.all/add/clear`). Щоб перенести прогрес на Supabase чи Firebase, достатньо замінити цей файл. Поле `profileId` у записах уже є на випадок появи профілів.

## Локальний запуск

Потрібен будь-який статичний сервер. Найзручніше — `tools/serve.py`: він вимикає кешування, тож після змін у коді браузер завжди бере свіжі файли. Відкриття `index.html` напряму як файлу не спрацює, бо модулі й `fetch` потребують HTTP.

```bash
python3 tools/serve.py
```

Застосунок: http://localhost:8765. Тести: http://localhost:8765/tests/.

## Екрани й адреси

| Адреса | Екран |
|---|---|
| `#/` | вибір класу (головна) |
| `#/about` | «Про застосунок» |
| `#/grade/g2` | розділи класу |
| `#/topic/g2-mul` | рівні розділу та статистика |
| `#/topic/g2-mul/play`, `/result` | сесія й підсумок (після перезавантаження повертають на рівні розділу) |

При першому запуску на будь-якій адресі спершу показується привітання. Після кнопки «Почати тренування» відкривається запитаний екран. Відмітка про те, що привітання вже бачили, зберігається в браузері (`mt.welcomed`).

Класи перелічені в `data/catalog.json`. Клас без розділів показується як «Незабаром».

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub і завантажте в нього вміст цієї папки.
2. Відкрийте **Settings → Pages → Build and deployment**, у полі **Source** виберіть *Deploy from a branch*, потім **Branch** `main` і **Folder** `/ (root)`.
3. За хвилину-дві сайт з'явиться за адресою `https://<username>.github.io/<repo>/`.

На безкоштовному тарифі GitHub Pages працює лише з публічними репозиторіями.

### Встановлення на Android

Відкрийте сайт у Chrome, потім **⋮ → Додати на головний екран** (або **Встановити застосунок**). Застосунок відкриватиметься на весь екран без адресного рядка.
