# Рівняння: необов'язковий крок «Обрати дію»

Статус: етап 1 (рівняння в одну дію) реалізовано — `equationSteps` у `js/core/generators.js`, екран у `js/app/main.js`; вмикається параметром `"steps": true`. Етапи 2 і 3 — далі.

## Навіщо

Розв'язати рівняння — це дві різні навички:

1. **Вибрати дію:** зрозуміти, яке число невідоме і якою оберненою дією його знайти.
2. **Виконати дію:** порахувати, з великими числами — стовпчиком.

Зараз обидві злиті в одну відповідь «x = □», і не видно, де саме дитина помилилася. Крім того, з великими числами («831 + x = 1263») порахувати в уяві важко, а стовпчика для рівнянь немає.

## Як працює

### 1. Рівняння й поле відповіді (як зараз)

```
831 + x = 1263
x = [    ]                 [Обрати дію]
```

Дитина, яка рахує в уяві, одразу вписує x — **крок вибору дії необов'язковий** і не сповільнює тих, кому він не потрібен.

### 2. «Обрати дію» (за бажанням)

Під рівнянням з'являється «Як знайти x?» і **чотири варіанти, підписані числами з прикладу**:

```
1263 − 831     1263 + 831     831 − 1263     831 + 1263
```

- Правильність вибору **не показуємо**.
- Варіанти — це 2 дії × 2 порядки двох відомих чисел. Неможливі для натуральних чисел варіанти («831 − 1263») лишаємо: помітити, що від меншого більше не віднімеш, — теж частина міркування.

### 3. Обчислення

Обраний вираз з'являється під рівнянням:

- **стовпчиком** — для `+`, `−`, `·` (з перемикачем напряму введення);
- **у рядок** — для `:` (ділення «кутом» поки немає; рахувати на чернетці).

Поле відповіді стовпчика підписане **«x =»**:

```
831 + x = 1263

        1263
  −
         831
  ──────────
  x = [     ]
       ←              ← перемикач напряму — під полем
  [Змінити дію]
```

- Поле «x = □» під рівнянням при цьому зникає — x вводиться в стовпчику.
- До відповіді можна «Змінити дію»: це нічого не підказує, бо правильність ще не показана.

### 4. Перевірка

- Дія вважається правильною, якщо дає x. Для `+` і `·` правильні обидва порядки чисел (переставна властивість: «34 + 82» і «82 + 34»), для `−` і `:` — лише один.
- Зараховується **лише правильне значення x**. Якщо дію обрано неправильно, а пораховано вірно, — відповідь неправильна.
- Після відповіді показуємо і правильне значення, і правильну дію: **«x = 432, бо x = 1263 − 831»**.

## Правильна дія для кожного виду рівняння

| Рівняння | Правильна дія | Схема назв |
|---|---|---|
| x + a = b, a + x = b | b − a | сума − доданок |
| x − a = b | b + a | різниця + від'ємник |
| a − x = b | a − b | зменшуване − різниця |
| x · a = b, a · x = b | b : a | добуток : множник |
| x : a = b | b · a | частка · дільник |
| a : x = b | a : b | ділене : частка |

Чотири варіанти завжди будуються з двох дій пари (`+`/`−` або `·`/`:`) і двох порядків чисел `a` і `b`.

## Коли пропонувати крок

Кнопка «Обрати дію» з'являється, якщо **два відомі числа разом мають ≥ 5 цифр** (45 + x = 312 — так; x + 7 = 15 — ні). Вмикається параметром завдання в `data/` (наприклад, `"steps": true`), щоб автор контенту вирішував, де це доречно.

## Зміна для всіх прикладів стовпчиком

Перемикач напряму введення (←/→) переноситься **під поле відповіді**. Ліворуч від поля звільняється місце для підпису «x =» у рівняннях; в інших прикладах там порожньо.

## Статистика

Для кожного прикладу, де дитина обирала дію, зберігаємо обрану дію, чи правильна вона і чи правильно її пораховано (порівнюємо введене з тим, що дає обрана дія — навіть неправильна).

Кожен нерозв'язаний приклад потрапляє **рівно в одну** категорію, тож сума категорій = кількість помилок:

| Категорія | Дія | Обчислення |
|---|---|---|
| неправильна дія | ✕ | ✓ |
| помилка в обчисленні | ✓ | ✕ |
| і дія, і обчислення | ✕ | ✕ |
| без вибору дії | — (відповідь одразу, причину не знаємо) | — |

У підсумку сесії (показуються лише непорожні категорії):

```
Не розв'язано: 4
неправильна дія: 1   помилка в обчисленні: 1   і дія, і обчислення: 1   без вибору дії: 1
```

Кожна помилка в рівнянні показується так (значки — білий ✕ у червоному колі, біла ✓ у зеленому):

```
137 + x = 578
твоя відповідь: x = 715 ⊗
обрана дія: x = 578 + 137 ⊗        ← червоним; правильна дія — зеленим із ✓
правильно: x = 441, бо x = 578 − 137
```

## Етапи

1. **Рівняння в одну дію** — усе, що описано вище.
2. **Рівняння у дві дії** — вони є в 5 класі (§ 18 Мерзляка: «4x + 128 = 600 → 4x = 472 → x = 472 : 4», «(x – 72) · 9 = 927», «14x + 4x – 48 = 240»). Вибір дії робиться послідовно для кожного кроку.
3. **Ділення «кутом»** — окрема задача; тоді й ділення в рівняннях з великими числами піде стовпчиком.
