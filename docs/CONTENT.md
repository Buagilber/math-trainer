# Формат контенту

Усі завдання лежать у `data/` у вигляді JSON. Застосунок завантажує їх під час кожного запуску, тому зміни в коді для нового контенту не потрібні: відредагували JSON, закомітили, і за хвилину-дві GitHub Pages публікує оновлення.

Перевірити контент після змін можна на сторінці `tests/index.html`. Тест «весь контент з data/ валідний» генерує по 200 прикладів з кожного завдання і повідомляє, якщо щось зламано. Зламане завдання застосунок просто пропускає й показує попередження внизу екрана розділів.

## Структура

```
data/
  catalog.json          — класи і список розділів
  topics/<id>.json      — один файл на розділ
```

### catalog.json

```json
{
  "version": 1,
  "levels": { "1": "Легко", "2": "Середньо", "3": "Складно" },
  "grades": [
    { "id": "g2", "grade": 2, "title": "2 клас", "topics": ["topics/g2-mul.json"] }
  ]
}
```

Поля класу:

| Поле | Опис |
|---|---|
| `topics` | Розділи в порядку показу |
| `notation` | Позначення класу. `{ "times": "·" }` — множення показується крапкою (як у підручнику 5 класу); без нього — `×` |
| `hiddenTopics` | Розділи, які поки не показуються (чернетки для інших класів). Застосунок їх ігнорує, тести перевіряють |

Щоб додати розділ, створіть файл у `topics/` і додайте шлях до нього в `topics` потрібного класу. Порядок у списку відповідає порядку на екрані. Новий клас додається новим об'єктом у `grades`.

### Розділ (topics/*.json)

| Поле | Обов'язкове | Опис |
|---|---|---|
| `id` | так | Унікальний ідентифікатор. **Не змінюйте після публікації**, бо до нього прив'язаний прогрес |
| `title` | так | Назва розділу |
| `icon` | ні | Емодзі для картки |
| `sessionSize` | ні | Скільки прикладів в одному тренуванні (за замовчуванням 10) |
| `prompt` | ні | Інструкція для завдань-записів розділу, що не мають своєї: «Знайди значення виразу.» (2 клас), «Обчисли.» (5 клас), «Розв'яжи рівняння.». Завдання з питанням у тексті («Скільки…?») її не отримують. Кожне завдання має мати інструкцію або питання — це перевіряє тест |
| `exercises` | так | Масив завдань |

### Завдання (exercises[])

Спільні поля:

| Поле | Опис |
|---|---|
| `id` | Унікальний у межах розділу, не змінюйте після публікації |
| `kind` | `"generator"` (генерує нові приклади щоразу) або `"fixed"` (конкретне завдання) |
| `difficulty` | Рівень 1, 2 або 3 (за замовчуванням 1) |
| `weight` | Як часто з'являється порівняно з іншими завданнями рівня (за замовчуванням 1) |
| `prompt` | Інструкція над завданням, як у підручнику: «Порівняй числа.», «Заміни іменоване число.», «Знайди неповну частку.» (до 90 символів). Потрібна, коли сам запис не каже, що робити («2 □ 14», «6 дес. 0 од. = □»). Порівнянням вона підставляється сама («Порівняй числа.» / «Порівняй вирази.»). Завданням-записам («34 + 53 = □», рівняння) без своєї інструкції дістається **інструкція розділу** |

| `hint` | Підказка: загальне правило чи спосіб для такого типу прикладів, без відповіді. Рядок або `{ "rules": [...], "scheme": [...] }` (див. [HINTS.md](HINTS.md)) |
| `hintAfterSec` | Через скільки секунд можна показати 💡, якщо стандартне правило не підходить |

`hint` можна задати й у самому розділі. Тоді вона показується для завдань без власної підказки.

Символ `□` у тексті позначає місце для відповіді. Якщо `□` у тексті немає (як у текстових задачах), поле відповіді виводиться під текстом.

## Фіксоване завдання

```json
{ "id": "m-cm", "kind": "fixed", "difficulty": 1, "text": "1 м = □ см", "answer": 100 }
```

З вибором варіанта:

```json
{ "id": "q1", "kind": "fixed", "text": "5 дм □ 48 см", "answer": ">", "choices": ["<", "=", ">"] }
```

Додаткові поля: `unit` (одиниця біля поля відповіді) і `shuffleChoices: true` (перемішувати варіанти).

## Генератори

### Значення змінних

Змінні використовуються в генераторах `template`, `expression` і `compare`, а формат `[min, max]` також у параметрах `a` і `b` генератора `arithmetic`:

| Запис | Значення |
|---|---|
| `[1, 9]` | ціле від 1 до 9 |
| `[10, 90, 10]` | від 10 до 90 з кроком 10 (10, 20, …, 90) |
| `{ "oneOf": ["Марійка", "Оленка"] }` | один з варіантів (зокрема текстовий) |

### Вирази

У формулах доступні `+ - * / %`, дужки й порівняння `< > <= >= == !=`. Ділення завжди має бути без остачі, інакше варіант відкидається і генерується новий. На екрані `*` показується як `×`, `/` як `:`, а `-` як `−`.

### `arithmetic`: приклади a ○ b = c

```json
{ "id": "two-one", "kind": "generator", "generator": "arithmetic", "difficulty": 1,
  "params": { "op": ["+", "-"], "a": [11, 98], "b": [1, 9], "result": [0, 100], "carry": "forbidden" } }
```

| Параметр | Опис |
|---|---|
| `op` | `"+"`, `"-"`, `"*"`, `"/"` або масив операцій |
| `a`, `b` | Діапазони компонентів. Для `/`: `b` задає дільник, `a` (необов'язково) обмежує ділене |
| `result` | Діапазон результату. Для `/` це діапазон частки |
| `carry` | `"required"` (лише з переходом через десяток), `"forbidden"` (лише без переходу), `"any"` |
| `missing` | Що приховати: `"result"` (за замовчуванням), `"a"`, `"b"`, `"operand"` (a або b), `"any"` |
| `commutative` | `true`: випадково міняє a і b місцями (для таблиці множення) |
| `unknown` | Буква для невідомого компонента, напр. `"x"`: рівняння пишеться як у підручнику («x − 34 = 82»), а відповідь вводиться окремим рядком «x = □». Без `unknown` невідоме — поле □ у самому прикладі |
| `steps` | `true`: необов'язковий крок «Обрати дію» для невідомого компонента — 4 варіанти оберненої дії числами з прикладу, питання «Як знайти невідомий доданок / зменшуване / …?». З `unknown` (рівняння з x) обрана дія рахується стовпчиком чи кутом; без `unknown` (□, 2 клас) — у рядок. З'являється, коли два відомі числа разом мають ≥ `stepsMinDigits` цифр (за замовчуванням 5; у 2 класі — 0, у рівняннях з · і : — 3). Див. [EQUATION-STEPS.md](EQUATION-STEPS.md) |
| `layout` | `"column"`: показувати стовпчиком (числа одне над одним, розряди під розрядами, поле відповіді під рискою). Працює для `+`, `−`, `×` з невідомим результатом; ділення цілих чисел — **кутом** (з «Розписати ділення»), множення на двоцифрове — з «Розписати множення»; приклади з пропущеним компонентом лишаються в рядок. Знак дії стоїть між двома числами. Відповідь типово вводиться справа наліво, як у зошиті; стрілка під полем перемикає напрям (вибір запам'ятовується на пристрої) |
| `columnAlign` | Для стовпчика: `"zeros"` — множення чисел, що закінчуються нулями, як у підручнику: остання ненульова цифра під останньою ненульовою, нулі винесені праворуч (`560 · 8`: вісімка під шісткою). Без параметра — розряди під розрядами |

### `expression`: обчисли значення виразу

```json
{ "id": "brackets", "kind": "generator", "generator": "expression", "difficulty": 2,
  "params": { "expr": ["a - (b + c)", "(a - b) + c"], "vars": { "a": [20, 80], "b": [2, 30], "c": [2, 30] },
              "result": [0, 100], "steps": [0, 100] } }
```

`expr` містить один вираз або масив виразів. `result` обмежує відповідь, `steps` обмежує кожен проміжний результат (щоб не виходити за межі 100 у проміжних діях).

### `compare`: постав знак <, = чи >

```json
{ "id": "expr-number", "kind": "generator", "generator": "compare", "difficulty": 2,
  "params": { "left": { "expr": "a + b", "vars": { "a": [10, 70], "b": [2, 29] }, "result": [0, 100] },
              "right": { "near": 5 } } }
```

Кожна сторона описується одним із трьох способів:
- `{ "number": [min, max] }`: число;
- `{ "expr": "...", "vars": {...}, "result": [...] }`: вираз;
- `{ "near": n }` (лише права сторона): число, що відрізняється від лівої частини не більше ніж на n.

`equalShare` (від 0 до 1, за замовчуванням 0.3) визначає, яку частку випадків, коли сторони рівні, залишати.

### `template`: довільний текст із формулою відповіді

Підходить для текстових задач, величин, периметра тощо.

```json
{ "id": "had-gave", "kind": "generator", "generator": "template", "difficulty": 1,
  "params": {
    "text": "У {name} було {a} {a|яблуко|яблука|яблук}. Вона віддала {b}. Скільки залишилось?",
    "vars": { "name": { "oneOf": ["Марійки", "Оленки"] }, "a": [5, 20], "b": [1, 9] },
    "where": ["a > b"],
    "answer": "a - b",
    "unit": "ябл."
  } }
```

| Параметр | Опис |
|---|---|
| `text` | Текст з підстановками (див. нижче) |
| `vars` | Змінні |
| `where` | Умови, які мають виконуватися (масив виразів) |
| `answer` | Формула відповіді |
| `result` | Діапазон відповіді (за замовчуванням ≥ 0) |
| `steps` | Діапазон проміжних результатів формули |
| `unit` | Одиниця біля поля відповіді |
| `answerPrefix` | Підпис перед полем відповіді замість «Відповідь:», напр. `"x ="` для рівнянь `"{k}x + {b} = {k * x + b}"` |

Підстановки в `text`:

| Запис | Результат (a = 3, b = 5) |
|---|---|
| `{a}` | `3` |
| `{a * 10 + b}` | `35` |
| `{=a + b}` | `3 + 5` (вираз у шкільному записі) |
| `{a\|гриб\|гриби\|грибів}` | `гриби` (форма слова для числа: 1 / 2–4 / 5+) |
| `{name}` | значення текстової змінної |

### `decimal`: десяткові дроби

Числа задаються цілими «одиницями» та кількістю знаків після коми: `"a": [12, 99], "aScale": 1` означає числа від 1,2 до 9,9. Уся арифметика точна, без похибок. Відповідь вводиться з комою, і «2,50» зараховується як «2,5».

```json
{ "id": "addsub-mixed", "kind": "generator", "generator": "decimal", "difficulty": 2,
  "params": { "op": ["+", "-"], "a": [11, 999], "aScale": 1, "b": [101, 999], "bScale": 2, "range": [0, 1000] } }
```

| `op` | Що генерує | Параметри |
|---|---|---|
| `+`, `-`, `*` | `a ○ b = □` | `a`/`aScale`, `b`/`bScale`; `range` обмежує результат (для `+` і `-`) |
| `/` | `a : b = □`, ділення без остачі | `b` (ціле), `result` і `aScale` задають частку |
| `round` | `Округли до <label>: 3,47 ≈ □` | `a`/`aScale`, `to` (скільки знаків лишити), `label` («цілих», «десятих», «сотих») |
| `compare` | `3,5 □ 3,48` | `a`/`aScale`, `bScale`, `near` (наскільки близькі числа, в одиницях) |

`"layout": "column"` працює й тут: для `+` і `−` вирівнювання кома під комою, для `×` по правому краю, як множать у зошиті.

### `fraction`: звичайні дроби з однаковими знаменниками

```json
{ "id": "add-mixed", "kind": "generator", "generator": "fraction", "difficulty": 3,
  "params": { "mode": "addMixed", "den": [4, 12], "whole": [1, 6], "carry": true } }
```

| `mode` | Приклад |
|---|---|
| `add`, `sub` | `1/6 + 4/6 = □` |
| `compare` | `5/11 □ 8/11` (кнопки < = >) |
| `toMixed` | `Запиши мішаним числом: 10/3 = □` |
| `toImproper` | `Запиши неправильним дробом: 5 6/9 = □` |
| `addMixed`, `subMixed` | `2 5/11 + 5 9/11 = □`; `carry: true` дозволяє перехід через одиницю |

`den` задає діапазон знаменника, `whole` — діапазон цілої частини. Рівні дроби зараховуються (2/4 = 1/2). Якщо очікується мішане число, ціла частина має збігатися, а дробова бути правильною.

### Запис дробів у тексті

У будь-якому тексті запис `3/4` показується «двоповерховим» дробом, а `1 2/7` — мішаним числом. Тому в шаблонах можна писати, наприклад, `"Знайди {a}/{b} від числа {b * k}"`.

### Ділення з остачею у `template`: крок «Обрати дію»

`"divideSteps": ["a", "b"]` — для задач на неповну частку («{a} = {b} × □ + {a % b}»): необов'язковий крок «Обрати дію» з варіантами `a : b`, `b : a`, `a · b`, `b · a`; обране ділення рахується кутом. Відповідь (`answer`) — неповна частка. Для задач на остачу — `{ "args": ["a", "b"], "find": "remainder" }`: питання «Як знайти остачу?», ділення одразу розписане, відповідь — остача. Див. [EQUATION-STEPS.md](EQUATION-STEPS.md#ділення-з-остачею).

### «Обрати дію» в задачах (`actionSteps` у `template`)

`"actionSteps": { "op": "*", "args": ["a", "b"], "question": "Як знайти площу?" }` — для задач в одну дію (площа, вартість, швидкість, час): необов'язковий крок «Обрати дію» з чотирма варіантами (`+`, `−`, `·`, `:` з тими самими числами; для `−` і `:` більше число першим). `args` — вирази зі змінних (`"a * b"`), `op` — правильна дія. `ops` — які дії пропонувати (за замовчуванням усі чотири; у 2 класі — `["+", "-"]` чи `["*", "/"]`, як у задачі, а в задачах «у … разів» — усі чотири, щоб розрізняти «на» і «у … рази»). `inline: true` — обчислення в рядок, без стовпчика (2 клас). Обрана дія рахується стовпчиком (множення двоцифрових — з «Розписати множення») чи кутом (з «Розписати ділення»). Ставимо на «Середньо» й «Складно», де числа вже не для усного рахунку.

### Порядок дій по кроках (`orderSteps` у `expression`)

`"orderSteps": true` — необов'язкове «Розв'язати по діях» для виразу: дитина торкається знака дії у виразі, рахує дію, вираз скорочується. Не та дія не виконується — з'являється правило з підручника (дужки; множення й ділення раніше; зліва направо). Множення й ділення можна виконувати в зручному порядку, якщо значення не змінюється й виходить ціле число. Ставимо там, де дій три й більше, є дужки чи множення разом з додаванням — не на елементарних «a + b − c».

### Розв'язання по діях (`multiStep` у `template`)

Для задач у кілька дій — необов'язкове «Розв'язати по діях» (docs/STEPS-ROLLOUT.md, етап 2). Схема й пояснення — за класом і рівнем (`catalog.json → grades[].multiStep`: `{"1": ["ask", "auto"], …}`; `ask` — ми питаємо, `free` — дитина складає сама; `auto` — пояснення підставляємо ми, `pick` — обирає дитина).

```json
"multiStep": {
  "numbers": ["a", "b", "c"],
  "plan": [
    { "op": "+", "args": ["b", "c"], "question": "Скільки учнів поїхало на екскурсію?" },
    { "op": "-", "args": ["a", "#1"], "question": "Скільки учнів залишилось у класі?" }
  ],
  "meanings": { "b + c": "поїхало на екскурсію", "a - b": "залишилось, коли поїхали хлопчики", "a - b - c": "залишилось у класі" },
  "spare": ["було в класі спочатку"]
}
```

- `numbers` — числа умови як вирази зі змінних, у порядку тексту (кнопки-числа в схемі Б).
- `plan` — дії схеми А; `"#1"` — результат дії 1; числа-сталі пишуться як є (`"2"`); `ops` — які дії пропонувати (за замовчуванням усі чотири).
- `meanings` — що означає проміжне число (вирази зі змінних); пояснення мають бути однозначними за умовою: якщо умова не каже, який вимір — довжина, а який ширина, пояснення загальне («площа грані»).
- `spare` — 1–2 явно хибні пояснення-відволікачі.
- Перевірка шляху схеми Б — за `answer` (дії дитини підставляються з іншими значеннями змінних).

### Відповідь з вибором у `template`

Якщо в `params` є `choices`, відповідь вибирається кнопками. `answer` — це умова (`true` означає перший варіант, `false` другий) або номер варіанта, починаючи з 0:

```json
{ "id": "by-3", "kind": "generator", "generator": "template",
  "params": { "text": "Чи ділиться {n} на 3?", "vars": { "n": [100, 999] }, "answer": "n % 3 == 0", "choices": ["Так", "Ні"] } }
```

### Фіксовані завдання з дробами

`fixed` приймає `answerType`: `"decimal"` (`"answer": "2,5"`) або `"fraction"` (`"answer": { "num": 3, "den": 4 }` чи `{ "whole": 1, "num": 1, "den": 2 }`).

### Клавіатура

Клавіатуру обирає тип відповіді: для цілих чисел показуються лише цифри, ⌫ і ✓, для десяткових додається «,», для звичайних дробів — поля «ціла частина / чисельник / знаменник» і кнопка «→» між ними. Тож у молодших класах зайвих кнопок не буде.

## Поради

- Після змін відкрийте `tests/index.html`. Якщо обмеження неможливо виконати (наприклад, `carry: "required"` при `a: [1, 2]`), тест покаже помилку.
- Не змінюйте `id` опублікованих розділів і завдань, бо від них залежить прогрес. Щоб прибрати завдання, видаліть його. Щоб змінити суть завдання, створіть нове з новим `id`.
- У відповіді (і в кожній частині дробу) може бути не більше 7 цифр. Завдання з довшою відповіддю валідатор відкидає.
- **Межі рівнів для множення** (issue #9): «Легко» — у межах таблиці множення (обидва множники до 10) або кругле число з однією ненульовою цифрою на одноцифрове (70 · 4); «Середньо» — двоцифрове на одноцифрове; «Складно» — двоцифрове на двоцифрове. Ділення — так само за діленим і дільником. Це стосується й текстових задач та задач на площу.
