# Підказки: специфікація

Реалізовано: правило в `js/core/hints.js`, інтерфейс у `js/app/main.js`, тексти в `data/topics/*.json`.

Мета: коли дитина довго не може розв'язати приклад, тихо запропонувати **загальне правило** для такого типу прикладів, без розв'язку конкретного завдання.

## 1. Коли з'являється кнопка

Кнопка 💡 з'являється, коли **одночасно** виконуються дві умови:

1. **Час на приклад перевищив поріг:**

   ```
   поріг = clamp(2 × мій_середній_час_на_цьому_рівні, мінімум, 45 с)
   мінімум = 15 с (рівень 1) · 20 с (рівень 2) · 25 с (рівень 3)
             +10 с для текстових задач (довгий текст без □)
   ```

   - «Мій середній час» — середній час на приклад в останній сесії цього рівня (уже рахується для статистики). Для першої сесії береться лише мінімум.
   - Підказка адаптується до дитини. Швидкій дитині кнопка з'явиться раніше, повільній пізніше, але не пізніше ніж через 45 с.
   - Автор контенту може задати свій поріг для завдання: `hintAfterSec`.

2. **Дитина не вводить відповідь:** поле порожнє або не змінювалося 8 с. Якщо дитина щойно набирає цифри, вона працює, і кнопка не з'являється.

Після правильної чи неправильної відповіді таймер скидається.

## 2. Як виглядає

- Невелика кнопка 💡 у верхній панелі, поруч із лічильником прикладів. Місце для неї зарезервоване, тож поява нічого не зсуває. Вона **плавно проявляється** приблизно за 1 с до 60% непрозорості.
- Без миготіння, підскакування, звуку й вібрації. Розмір менший за кнопки клавіатури, колір приглушений.
- Тап відкриває невелику картку під прикладом: 1–3 короткі речення і, за потреби, міні-приклад **з іншими числами**. Закривається кнопкою «Зрозуміло» або повторним тапом на 💡.
- Кнопка залишається до кінця цього прикладу, щоб можна було перечитати.

## 3. Що пише підказка

- **Правило або спосіб, а не відповідь.** Наприклад: «Додавай окремо десятки й окремо одиниці: 34 + 25 → 30 + 20 = 50, 4 + 5 = 9, разом 59».
- **Коротко.** До 200 символів. Для 1–2 класу 1–2 речення простими словами.
- **На «ти»**, доброзичливо, без «неправильно» і «ти помилився».
- **Без чисел із поточного прикладу**, щоб підказка не стала розв'язком.

## 4. Де зберігається (формат контенту)

```json
{
  "id": "g2-addsub-no-carry",
  "hint": "Додавай окремо десятки й окремо одиниці.",
  "exercises": [
    { "id": "two-two", "hint": "34 + 25: десятки 30 + 20 = 50, одиниці 4 + 5 = 9, разом 59.", ... },
    { "id": "two-two-missing", "hint": "Щоб знайти невідомий доданок, від суми віднімай відомий доданок.", "hintAfterSec": 25, ... }
  ]
}
```

- `hint` у завданні — головна підказка. `hint` у розділі — запасна для завдань, у яких своєї немає.
- Якщо підказки немає ніде, кнопка не з'являється.
- Пізніше можна додати підказку з картинкою (`hintImage`), наприклад числову пряму чи розбиття на десятки.

## 5. Статистика

- У результаті прикладу зберігається `hintUsed: true/false`.
- **Зірки й точність не зменшуються**: мета — навчитися, а не покарати. Час на приклад рахується як є.
- У підсумку сесії з'являється нейтральний рядок «Підказкою скористались: 2 рази». На екрані рівня можна показувати частку прикладів із підказкою. Якщо вона падає, дитина вчиться.

## 6. Ухвалені рішення

- **Зірки не знімаємо** навіть за часте користування підказкою: це тренажер, а не іспит.
- **Підказки вмикаємо для всіх класів.** У 1–2 класі підказку може прочитати хтось із батьків. Вона допомагає коротко пояснити дитині спосіб розв'язання.
- **Вимикання підказок і батьківський контроль** — пізніше, разом з авторизацією та персональною статистикою.
